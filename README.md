# AI Operations Portfolio

Automazioni AI per il settore engineering/manifatturiero, costruite con n8n, Claude API, Resend e Supabase.

## Progetti

### Progetto 01 — Document Classifier AI
Classifica automatica di documenti tecnici industriali (P&ID, disegni, specifiche) tramite Claude AI con instradamento su 4 categorie.

### Progetto 02 — PDM Revision Notifier
Monitoraggio automatico revisioni documenti CAD/PDM da Google Sheets con notifica email al responsabile.

### Progetto 03 — Drawing Approval Agent
Agente AI che verifica la completezza dei campi obbligatori di un disegno tecnico e invia approvazione o rifiuto automatico.

### Progetto 04 — AI Document Summarizer
Ricezione documenti via webhook, riassunto automatico tramite Claude API e invio email con il risultato.

### Sistema — Error Handler
Gestione errori centralizzata con notifica email immediata e logging su database PostgreSQL.

## Stack tecnologico
- n8n (orchestrazione workflow)
- Claude API (AI processing)
- Resend (email transazionali)
- Supabase (database PostgreSQL + logging)
- Docker (ambiente containerizzato)
- GitHub (versioning)
